# Yusra

A Post-Silicon Digital Entity. 100% offline, private, powerful.

## Install

### Windows
Download `Yusra_*_Windows_x64-setup.exe` from [Releases](https://github.com/HASH-CREATES/Yusra/releases) and run it.

### macOS
Download `Yusra_*_macOS_*_universal.dmg` from [Releases](https://github.com/HASH-CREATES/Yusra/releases), open it, and drag Yusra to Applications.

### Build from source

```bash
# Prerequisites: Node.js 20+, Rust stable, Tauri CLI
git clone https://github.com/HASH-CREATES/Yusra.git
cd Yusra
npm install
npm run tauri dev
```

## Features

- **3D Entity Orb** — Real-time 3D visualizer that reacts to Yusra's state
- **Local AI Models** — Downloads and runs GGUF models (Qwen, etc.) on your device
- **Agentic Loop** — Yusra can think, speak, and execute commands with your approval
- **Danger System** — Risky commands require explicit confirmation
- **Memory** — Persistent context across sessions
- **100% Offline** — No data ever leaves your machine
